Self Bookmark Mail プライバシーポリシー

最終更新日: 2026年8月15日

1. 取得・利用する情報

Self Bookmark Mailは、ユーザーが設定した送信先メールアドレス、ユーザーが送信操作を行ったWebページのタイトルとURL、ブックマーク名利用機能を有効にした場合の一致するブックマーク名を、メール送信機能の提供に必要な範囲で取り扱います

2. Googleユーザーデータ

Gmail APIの gmail.send スコープを使用し、ユーザーの明示的な操作によりGmailからメールを送信します。受信メールの読み取り、メール一覧の取得、削除、変更は行いません

3. 保存

送信先メールアドレスと設定値は、ユーザーの端末内のChrome拡張機能ローカルストレージに保存します。OAuthアクセストークンはSelf Bookmark Mail独自のストレージには保存せず、Chrome Identity APIの仕組みで管理します

4. 外部送信・第三者提供

メール送信に必要な情報はGoogleのGmail APIへHTTPSで送信されます。Self Bookmark Mailの開発者が運営するサーバーへの送信・保存、広告目的での利用、データ販売、その他の第三者提供は行いません

5. ブックマーク権限

ブックマーク名をメールタイトルに利用する機能をユーザーが有効にした場合だけ、Chromeのブックマーク権限を要求します。この権限は一致するブックマーク名を読み取るためだけに使用し、ブックマークの作成、編集、削除は行いません

6. データの削除

拡張機能をアンインストールすると、Self Bookmark MailがChrome拡張機能ローカルストレージに保存した設定は削除されます。Googleアカウントとの接続は設定画面から解除できます

7. Google API Services User Data Policy

Google APIから取得した情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従い、Self Bookmark Mailのユーザー向けメール送信機能を提供する目的に限定します

8. セキュリティ

Google APIとの通信にはHTTPSを使用します。Self Bookmark Mailは、機能提供に不要なユーザーデータを収集しません

9. 変更

本ポリシーを変更する場合は、利用するデータや目的に重要な変更があるときに公開内容を更新します
