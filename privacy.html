Self Bookmark Mail Privacy Policy / プライバシーポリシー

English / 日本語

Last updated: August 17, 2026

1. Information We Use

Self Bookmark Mail handles the recipient email address you configure, the title and URL of a web page when you explicitly send it, and a matching bookmark name when the bookmark-name option is enabled, only as needed to provide the email-sending feature.

2. Google User Data

Self Bookmark Mail uses the Gmail API gmail.send scope to send email from Gmail only when you explicitly request it. The extension does not read received email, list messages, delete email, or modify email.

3. Storage

The recipient email address and extension settings are stored in Chrome extension local storage on your device. OAuth access tokens are not stored in Self Bookmark Mail storage and are managed through the Chrome Identity API.

4. External Transmission and Third Parties

Information required to send an email is transmitted to Google's Gmail API over HTTPS. It is not sent to or stored on a server operated by the developer, used for advertising, sold, or otherwise provided to third parties.

5. Bookmark Permission

Chrome bookmark permission is requested only when you enable the option to use bookmark names as email subjects. It is used only to read the matching bookmark name. The extension does not create, edit, or delete bookmarks.

6. Data Deletion

Uninstalling the extension removes settings stored by Self Bookmark Mail in Chrome extension local storage. You can disconnect your Google Account from the Settings page.

7. Google API Services User Data Policy

Self Bookmark Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and is limited to providing the user-facing email-sending feature.

8. Security

Communication with Google APIs uses HTTPS. Self Bookmark Mail does not collect user data that is unnecessary for providing its functionality.

9. Changes

If this policy changes, the published policy will be updated when there is a material change to the data used or the purpose of use.

10. Contact

Contact us through GitHub Issues.

1. 取得・利用する情報

Self Bookmark Mailは、ユーザーが設定した送信先メールアドレス、ユーザーが送信操作を行ったWebページのタイトルとURL、ブックマーク名利用機能を有効にした場合の一致するブックマーク名を、メール送信機能の提供に必要な範囲で取り扱います

2. Googleユーザーデータ

Gmail APIの gmail.send スコープを使用し、ユーザーの明示的な操作によりGmailからメールを送信します。受信メールの読み取り、メール一覧の取得、削除、変更は行いません

3. 保存

送信先メールアドレスと設定値は、ユーザーの端末内のChrome拡張機能ローカルストレージに保存します。OAuthアクセストークンはSelf Bookmark Mail独自のストレージには保存せず、Chrome Identity APIの仕組みで管理します

4. 外部送信・第三者提供

メール送信に必要な情報はGoogleのGmail APIへHTTPSで送信されます。Self Bookmark Mailの開発者が運営するサーバーへの送信・保存、広告目的での利用、データ販売、その他の第三者提供は行いません

5. ブックマーク権限

ブックマーク名をメールタイトルに利用する機能をユーザーが有効にした場合だけ、Chromeのブックマーク権限を要求します。この権限は一致するブックマーク名を読み取るためだけに使用し、ブックマークの作成、編集、削除は行いません

6. データの削除

拡張機能をアンインストールすると、Self Bookmark MailがChrome拡張機能ローカルストレージに保存した設定は削除されます。Googleアカウントとの接続は設定画面から解除できます

7. Google API Services User Data Policy

Google APIから取得した情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従い、Self Bookmark Mailのユーザー向けメール送信機能を提供する目的に限定します

8. セキュリティ

Google APIとの通信にはHTTPSを使用します。Self Bookmark Mailは、機能提供に不要なユーザーデータを収集しません

9. 変更

本ポリシーを変更する場合は、利用するデータや目的に重要な変更があるときに公開内容を更新します

10. お問い合わせ

GitHub Issues からお問い合わせください
